Build the APK

        
    
          
  1. Install Android Studio with the Android SDK for platform 34.
    2. 
          
  2. Open the unzipped folder and wait for Gradle sync. Android Studio creates the Gradle wrapper.
    3. 
          
  3. Choose Build, then Build APK(s). The debug APK is in app/build/outputs/apk/debug/.
    4. 
        

        
The ZIP also contains README-BUILD.md with release signing steps. HTML Studio generates source files only. It does not compile the APK.

      

    


    

      

        
        
        
        
        
        
        
        

      

      

      

        
Build the EXE

        
    
          
  1. Install the .NET 8 SDK on Windows 10 or 11.
    2. 
          
  2. Open a terminal in the unzipped folder and run the publish command in README-BUILD.md.
    3. 
          
  3. The executable is written to bin, then Release, then net8.0-windows, then win-x64, then publish.
    4. 
        

        
The app uses WebView2 and does not bundle Electron, NW.js, Tauri or Chromium. HTML Studio generates source files only.

      

    


    

      

        
Publish a project on GitHub Pages

        
    
          
  1. Choose a project and build its GitHub Pages bundle. The bundle contains your files, an empty .nojekyll file and a README.md.
    2. 
          
  2. Create a GitHub repository and upload the bundle contents to the root of the main branch.
    3. 
          
  3. Open Settings, then Pages. Under Build and deployment, select Deploy from a branch, then main and / (root).
    4. 
          
  4. Open the URL GitHub shows after the first deployment finishes.
    5. 
        

        
HTML Studio itself is deployed the same way: upload this folder to the repository root.
